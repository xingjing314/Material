### T001

**主题名称**：教材由多套知识体系拼合而成，并非天然统一的教学体系

**归一化描述**：  
五份材料均指出：第四版教材同时容纳信息化/技术、信息系统治理与工程、项目管理过程体系、绩效域、高级项目管理、管理科学、组织治理与管理、法律法规等不同知识板块；这些板块更多是因考试覆盖需要被放在同一本书中，而不是天然自洽、统一串联的教学体系。教材整体更接近“知识集合 / 复合知识手册 / 系统知识地图”。

**来源**：
```text
my
deepseek
grok
meta_ai
qwen
```

**各来源对应观点**：

| 来源 | 对应表述要点 |
|---|---|
| `my` | 教材不是天然自洽教学体系；多体系放在同一本书但关系解释不足；更像“知识集合”。 |
| `deepseek` | 知识范围极广；多个知识体系并非天然统一，因考试要求被“拼合”；多体系拼合带来认知负荷。 |
| `grok` | 知识跨度很大，横跨技术、项目管理、管理科学、组织管理、法律等不同体系；内部系统联系不够显性。 |
| `meta_ai` | 百科全书型、覆盖型教材；不同部分组织逻辑并不一致；整本并非完全统一知识结构。 |
| `qwen` | 复合型知识手册；多个知识体系“拼合”，并非天然统一；知识跨度超出传统项目经理单一职责范围。 |

**关系类型**：`normalized_same`

**语义边界**：
- **包括**：多知识体系并存、拼合、非天然统一、整体像知识集合/百科覆盖。
- **不包括**：过程体系与绩效域的双轨范式差异（见 T002）；广度导致深度不足（见 T003）；教材作为“能力训练系统缺失”的定位（见 T004）。

### T002

**主题名称**：传统过程导向体系与绩效域/价值导向体系双轨并存，且教材对二者整合、协同与转换解释不足

**归一化描述**：  
五份材料均指出：教材同时保留以十大知识领域、过程、ITTO、计划与控制为代表的过程范式，以及以绩效域、价值交付、原则、结果、敏捷/系统思考为代表的价值/结果导向范式；两套体系并存但未充分融合。学习者需要自行完成体系间关系建构；考试也可能要求在两套话语之间切换或协同使用。

**来源**：
```text
my
deepseek
grok
meta_ai
qwen
```

**各来源对应观点**：

| 来源 | 对应表述要点 |
|---|---|
| `my` | 十大知识领域偏过程/计划/控制；绩效域偏价值/结果/适应/敏捷/系统思考；教材未充分完成范式转换与统一解释。 |
| `deepseek` | “知识框架双轨制”；过程与绩效并存未完全融合；关系解释不足；并列/互补/替代关系不清；学习者需自己建构关系。 |
| `grok` | 过程范式与价值/结果导向范式并存；协同、转换、裁剪解释不足；两者不是简单替代；考试可能要求共同使用。 |
| `meta_ai` | 明显“双轨制”；术语与范式并存（如风险管理过程 vs 不确定性绩效域）；双轨未统一是最重要结构性问题之一。 |
| `qwen` | 明显“双轨制管理逻辑”；前者关注“怎么做”，后者关注“为什么做/结果与价值”；融合是核心结构问题之一。 |

**关系类型**：`normalized_same`

**语义边界**：
- **包括**：过程 vs 绩效/价值双范式并存、整合不足、考试可能要求切换/协同。
- **不包括**：教材整体多体系拼合（T001）；绩效域自身抽象与易误解问题（T006）；绩效域考试权重上升趋势（T019）。

### T003

**主题名称**：教材覆盖范围极大，导致单一主题解释深度受限，且不同板块解释深度不均

**归一化描述**：  
多份材料指出：为覆盖极广考试范围，教材呈“大而全”；单个主题可给予的解释深度有限，很多内容偏概念、框架与标准表述。不同板块内部完整程度也不一致——例如十大知识领域相对更系统，信息化前几章概念密集但深度有限，组织治理、管理科学等后部内容更压缩，部分知识“点到为止”。

**来源**：
```text
deepseek
grok
meta_ai
qwen
```

**各来源对应观点**：

| 来源 | 对应表述要点 |
|---|---|
| `deepseek` | 不同章节概念解释深度不均；十大知识领域相对系统；信息化概念密集深度有限；后部章节较压缩；部分知识点到为止。 |
| `grok` | 存在“广度与深度”矛盾；覆盖极广导致单一主题理解深度不足；很多内容偏概念、框架和标准表述。 |
| `meta_ai` | 广度过载；为覆盖综合知识必须大而全；单一领域讲解深度易受限；某些章节更像知识点罗列。 |
| `qwen` | 知识跨度极大；另用“宽进严出/学海考针”描述学习极宽与考查可能很深的反差（与本主题相关但见 T030 独立保留）。 |

**关系类型**：`normalized_same`（`qwen` 在本主题上为部分覆盖，其“宽进严出”另立 T030）

**语义边界**：
- **包括**：因覆盖广导致深度受限；章节间深度不均。
- **不包括**：多体系是否统一（T001）；“学宽考深”的考试机制表述（T030）。

### T004

**主题名称**：教材整体定位为覆盖型知识地图/知识索引/百科全书，主要提供知识原材料，而非能力训练系统或直接应试手册

**归一化描述**：  
五份材料从不同措辞描述同一教材定位：教材更偏告诉读者“有什么”、提供标准化理论与方法框架、充当知识载体/原材料/知识地图；较少系统训练“什么情况下用、为什么用、如何协同、真实项目会遇什么问题”，也不是直接面向考试答题的学习手册。

**来源**：
```text
my
deepseek
grok
meta_ai
qwen
```

**各来源对应观点**：

| 来源 | 对应表述要点 |
|---|---|
| `my` | 更像知识集合，而非天然形成认知体系的教学材料。 |
| `deepseek` | 更像知识索引而非能力训练系统；偏理论与方法框架；实践场景嵌入不足。 |
| `grok` | 以覆盖为导向；更接近系统知识地图，而非直接面向考试答题的学习手册；理论—现实转换桥梁较弱。 |
| `meta_ai` | 百科全书型、覆盖型；相对静态的知识最大公约数。 |
| `qwen` | 主要提供考试所需“知识原材料”；理解教材只是第一步。 |

**关系类型**：`normalized_same`

**语义边界**：
- **包括**：教材定位为覆盖/索引/原材料/百科。
- **不包括**：教材与考试之间“知识陈列 vs 能力应用”的结构性张力机制（T005）；掌握教材是否等于通过考试（T018）。

### T005

**主题名称**：教材与考试之间存在“知识陈列/覆盖”与“能力应用/任务表现”的结构性张力，中间缺少系统的知识→能力转换层

**归一化描述**：  
多份材料指出：教材按知识域/知识陈列组织，考试则按场景、任务与能力表现组织；大纲也不仅要求知识掌握，还要求实际项目管理与综合应用能力。因此“知道教材内容”与“能在考试任务中正确使用”之间存在结构性落差，中间缺少系统转换层。

**来源**：
```text
my
deepseek
grok
meta_ai
qwen
```

**各来源对应观点**：

| 来源 | 对应表述要点 |
|---|---|
| `my` | 理解甚至精通教材不等于通过充分条件；还需要迁移、情景判断、案例表达、论文实践、教材外知识与应试能力。 |
| `deepseek` | 教材更偏知识陈列，考试更强调能力应用；匹配关系不稳定；核心问题之一是知识陈列 vs 能力应用，缺少知识→能力转换层。 |
| `grok` | 大纲明确要求实际项目管理能力，不是单纯知识目录；存在知识覆盖与任务表现差异；掌握教材不能直接等价于具备考试通过能力。 |
| `meta_ai` | 大纲不仅规定知识还规定能力；某些能力要求无法直接对应到某一教材章节；会背教材不等于会分析案例/完成论文。 |
| `qwen` | 大纲更像能力画像，教材更像知识载体，真实考试检验知识能否在任务中被正确调用；大纲能力要求不能靠单纯阅读教材自动获得。 |

**关系类型**：`normalized_same`

**语义边界**：
- **包括**：教材组织方式与考试任务组织方式的错位；缺少转换层；能力要求超出纯知识目录。
- **不包括**：教材自身“是不是百科全书”的定位（T004）；教材/实践/考试三世界距离（T015）；翻译能力本身（T016）。

### T006

**主题名称**：绩效域本身抽象度高、教材解释不足，容易被误解，且其考试重要性可能高于教材篇幅所体现的重要性

**归一化描述**：  
若干材料专门指出绩效域板块自身的问题：篇幅有限但考试重要性较高；概念更原则化、抽象，并涉及用户故事、史诗、价值流等敏捷与价值驱动概念；教材上下文支持不足。DeepSeek 进一步指出：教材可能把绩效域拆成类似“过程要点”，使人误以为绩效域也是固定执行流程。Grok 与 My 强调其主观题重要性可能明显高于篇幅比例。

**来源**：
```text
my
deepseek
grok
```

**各来源对应观点**：

| 来源 | 对应表述要点 |
|---|---|
| `my` | 绩效域篇幅有限但考试重要性较高；抽象度高；涉及更多敏捷与价值驱动概念；现实解释与上下文支持不足。 |
| `deepseek` | 绩效域强调原则、价值、结果；教材又可能拆成过程要点形式；易被误解为固定执行流程。 |
| `grok` | 绩效域在教材中篇幅有限；近年案例和论文考查明显增强；主观题重要性可能明显高于篇幅比例；长期权重仍有不确定性。 |

**关系类型**：`normalized_same`（三源同义；`meta_ai`/`qwen` 谈双轨与抽象，但未同样明确“篇幅 vs 考试重要性/易误解为流程”这一组合现实，故不计入本主题来源）

**语义边界**：
- **包括**：绩效域抽象、解释不足、易误解、篇幅与考试重要性不匹配。
- **不包括**：双轨并存结构本身（T002）；绩效域命题趋势扩展（T019）。

### T007

**主题名称**：第四版教材与考试大纲在知识范围/目录层面高度对应，但二者角色不同：大纲描述“应考什么/能力要求”，教材解释“知识是什么”

**归一化描述**：  
多份材料认为：大纲主要知识范围基本能在第四版教材找到对应章节，二者高度对应；但大纲与教材不是同一个东西——大纲描述考试应覆盖的知识与能力，教材负责解释知识内容；大纲不规定教材具体解释深度，也不等于能力会自动从阅读教材中获得。

**来源**：
```text
deepseek
grok
meta_ai
qwen
```

**各来源对应观点**：

| 来源 | 对应表述要点 |
|---|---|
| `deepseek` | 教材与大纲高度对应但不是同一个东西；大纲描述应考什么，教材解释知识是什么；大纲不规定讲到多深。 |
| `grok` | 第四版与 2022 大纲高度对应；大纲范围基本都能在教材找到对应；大纲也明确要求实际项目管理能力。 |
| `meta_ai` | 与 2022 大纲高度对应；目录层面高度对应，但大纲还规定能力；某些能力无法直接对应章节。 |
| `qwen` | 大纲更像能力画像，教材更像知识载体；大纲还要求大型复杂项目管理、综合运用与高级实践能力。 |

**关系类型**：`normalized_same`

**语义边界**：
- **包括**：教材—大纲对应关系与角色分工。
- **不包括**：大纲是否“大于”教材的具体溢出项（见 T028）；真实考试是否等于教材（T008）。

### T008

**主题名称**：教材是主要考试依据，但不是唯一/完全封闭边界；真实考试可在教材基础上做加减法、动态抽样与新情景扩展

**归一化描述**：  
五份材料共同指向：教材是主要知识来源与基础，但真实考试不会按教材篇幅均匀抽题；可能某些内容当次不考、某些权重突然提高；可能加入新技术、新政策、新业务情景；部分答题规范与采分要求也不完全由教材直接提供。因而“掌握教材”不能直接等价于“具备考试通过能力”。真实考试知识空间可以大于单纯教材表述范围。

**来源**：
```text
my
deepseek
grok
meta_ai
qwen
```

**各来源对应观点**：

| 来源 | 对应表述要点 |
|---|---|
| `my` | 大纲和教材都不能完全罩住真实考试；真实应试知识空间大于单纯教材知识空间。 |
| `deepseek` | 综合知识存在动态边界；教材对考试边界定义不完整；真实考试可能对教材做加减法；教材是主要依据但非唯一。 |
| `grok` | 教材与真实考试并非完全等价；不会按篇幅均匀抽题；新技术/政策/绩效域应用可能超出概述深度；部分答题规范不由教材直接提供。 |
| `meta_ai` | 真实考试是动态抽样与动态扩展；可能出现教材外新情景；教材可能大于单次考试；新情景仍可能要求使用底层项目管理原理。 |
| `qwen` | 教材不能完全覆盖动态考试环境；真实考试可能在教材基础上延伸；需把基本原理迁移到新场景。 |

**关系类型**：`normalized_same`

**语义边界**：
- **包括**：教材非完全边界；考试加减法/抽样/扩展；掌握教材≠自动通过。
- **不包括**：稳定核心与动态边缘的内容结构划分（T011）；静态教材 vs 动态技术政策的时效矛盾机制表述若需单独强调见 T009 相关描述；答题规范不由教材提供的细节侧写见 `grok` 在本主题中的表述。

## 5. Apparent Conflicts

### C001

- **冲突 ID**：`C001`
- **涉及主题**：T012（案例分析机制）、T026（My：稳定得分空间缩小）、T010（稳定核心）
- **来源 A 及其观点**：
  - `deepseek`：计算仍是案例重要组成部分；计算具有相对稳定性，但具体比例可能变化。
  - `grok`：计算部分相对稳定；挣值等经典计算、网络图等传统计算相对具有可预测性。
- **来源 B 及其观点**：
  - `my`：第四版后计算范围变宽（工程经济学、运筹学等）；传统计算题权重相对下降；“找茬+经典计算”可稳定预测的总分空间减少；考试从固定套路向灵活应用移动。
- **冲突具体在哪里**：
  - 争议点不是“案例还要不要考计算”，而是 **经典计算作为可预期稳定得分区域的程度**：A 侧强调相对稳定/可预测；B 侧强调稳定得分空间在缩小、范围变宽后确定性下降。
- **是否可能只是口径/时间/层级不同**：
  - **可能**。例如：A 侧说的是“计算仍常考、公式类相对比纯开放分析更稳定”；B 侧说的是“相对过去套路化得分区，第四版后范围与权重变化导致可预期性下降”。二者可能同时成立于不同比较基线（绝对稳定性 vs 相对历史变化）。
- **本轮裁决**：不裁决谁正确；两说并陈，供后续证据审查。

### C002

- **冲突 ID**：`C002`
- **涉及主题**：T005、T007、T008
- **来源 A 及其观点**：
  - `deepseek`：教材、考纲、真实考试之间的匹配关系 **并不稳定**；教材偏知识陈列、考试偏能力应用。
- **来源 B 及其观点**：
  - `grok` / `meta_ai`：第四版教材与 2022 大纲 **高度对应**；教材范围与真实考试 **高度相关**（同时承认不能替代考试能力）。
- **冲突具体在哪里**：
  - 对“教材—大纲—考试”匹配关系的语气与判断强度：A 强调不稳定/张力；B 强调高度对应/高度相关。
- **是否可能只是口径/层级不同**：
  - **很可能**。B 多指 **目录/知识范围对应**；A 多指 **组织逻辑与能力考查层面的结构性错位**。未必是对同一命题的直接否定。
- **本轮裁决**：不裁决；标记为表观冲突兼可能分层表述差异，与 U001 联动。
